# Módulo 1: Introducción a Playwright

Este módulo cubre los conceptos fundamentales antes de escribir una sola línea de código. Si venís de QA manual sin experiencia previa en automation, arrancá por acá.

## Contenido del módulo

1. [¿Qué es Playwright?](./que-es-playwright.md)
   - Origen, propósito y contexto
   - Por qué existe y qué problema resuelve

2. [Features principales](./features.md)
   - Auto-wait, Trace Viewer, UI Mode, Codegen
   - Web-first assertions, network interception, contextos aislados

3. [Ventajas y desventajas](./ventajas-desventajas.md)
   - Cuándo Playwright es la mejor opción
   - Sus limitaciones honestas

4. [Comparación con otras herramientas](./comparacion.md)
   - Playwright vs Selenium, Cypress y Puppeteer
   - Cuándo conviene cada una

## Objetivos de aprendizaje

Al terminar este módulo vas a poder:

- Explicar qué es Playwright y para qué sirve
- Enumerar sus features más importantes
- Justificar por qué elegirlo frente a otras herramientas
- Identificar sus limitaciones para no venderle humo a nadie

## Duración estimada

30 a 45 minutos de lectura.
