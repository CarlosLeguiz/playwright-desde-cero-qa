# Módulo 2: Instalación y setup

En este módulo vas a instalar Playwright desde cero en tu máquina y entender cada pieza que se crea en el proceso.

## Contenido del módulo

1. [Requisitos previos](./requisitos-previos.md)
   - Node.js, npm y VS Code
   - Cómo verificar qué tenés instalado

2. [Instalación paso a paso](./paso-a-paso.md)
   - Crear la carpeta del proyecto
   - Ejecutar `npm init playwright@latest`
   - Qué elegir en cada pregunta del instalador

3. [Estructura del proyecto](./estructura-del-proyecto.md)
   - Explicación de cada carpeta y archivo
   - Qué se toca, qué no se toca, qué se sube a Git

## Objetivos de aprendizaje

Al terminar este módulo vas a poder:

- Tener Playwright funcionando en tu máquina
- Entender qué crea la instalación y por qué
- Identificar cada archivo del proyecto y su propósito
- Saber qué carpetas y archivos NO se suben a Git

## Duración estimada

30 a 40 minutos entre lectura e instalación.
